# Nova Roadmap

## Delivered foundation
- v1.0: local-first personal assistant, deterministic intents, SQLite memory, notes/tasks, approved aliases, safe calculator, confirmation-gated URL opening and deletion.
- v1.1 core: shared domain contracts, deterministic planning, policy-mediated execution, environment inspection and read-only developer project inventory.

## Next milestones
- v1.2 Personal intelligence: contextual follow-ups, memory search/ranking, explicit preference profiles, correction review and optional wake-word voice/TTS.
- v1.3 Operating environment: Windows desktop UI, notifications, app launching and browser workflows behind per-action approval.
- v1.4 Developer assistant: repository indexing, architecture explanations, test execution in an isolated workspace, patch preview and approval-gated writes.
- v1.5 Unified workflows: multi-step plans, resumable runs, rollback records and user-visible execution history.
- v2.0 platform: extension SDK, desktop/mobile clients and optional Aegis execution adapter.

## Non-goals
- No mandatory LLM, cloud dependency or background surveillance.
- No arbitrary shell execution or silent file modifications.
- Aegis is a separate project and is not bundled into Nova.
