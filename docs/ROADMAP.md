# Roadmap after v1.0

- v1.1 Context: richer entity extraction, multi-turn clarification, configurable context expiry.
- v1.2 Voice: improved offline wake-word flow, configurable audio devices, accessibility controls.
- v1.3 Desktop: tray UI, app launching through explicit allowlists, file search with scoped permissions.
- v1.4 Integrations: plugin contracts and user-granted connectors; optional Aegis execution adapter.
- v2.0 Extensibility: signed skill packages, portable backup, policy profiles, expanded language support.

Nova remains LLM-independent. Learning remains inspectable and user-approved; Nova will not rewrite its own source code.
