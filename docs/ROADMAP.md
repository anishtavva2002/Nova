# Nova roadmap

- **v0.1 Core:** CLI, deterministic intents, skill registry, policy gate, SQLite memory, tests.
- **v0.2 Context:** entity extraction, clarification, bounded conversational context, audit events.
- **v0.3 Skills:** allowlisted file search, app launcher, safe browser opening, tasks and reminders.
- **v0.4 Voice:** speech adapters, wake word, push-to-talk and microphone privacy controls.
- **v0.5 Desktop:** tray app, background service, permission prompts and diagnostics.
- **v1.0 Hardening:** threat model, skill verification, memory export/deletion, optional Aegis adapter.

Non-goals: LLM dependency, silent arbitrary shell execution, autonomous code mutation, unbounded background monitoring.
